# NOOR | نور — PWA prototype

Included: responsive Arabic/English UI, tasbeeh counter saved on device, Quran surah index and Uthmani Arabic surah text fetched from AlQuran Cloud, basic installable PWA shell.

Important: Quran content needs internet when fetched. The app shell can cache, but the complete Quran is not downloaded for offline use yet. The adhkar list is only an initial sample, NOT a complete verified library. Audio, tafsir, search, full adhkar collection, notifications and offline Quran are not implemented yet. Do not publish as a complete religious reference until content and references are reviewed.

## Install on Android using only a phone
Host the files on HTTPS. One free option for a public project is GitHub Pages:
1. Create a public GitHub repository.
2. Upload all five files to its root.
3. In Settings > Pages, deploy from branch `main`, folder `/ (root)`.
4. Open the resulting Pages address in Chrome.
5. Chrome menu > Install app / Add to Home screen.

The PWA prototype has no ads and no app subscription. Hosting provider terms and limits apply.
