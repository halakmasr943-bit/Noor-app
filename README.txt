NOOR v2 — ملفات تحديث نور

المحتويات:
- index.html: الواجهة، القرآن، الأذكار، المسبحة، المحفوظات.
- manifest.webmanifest: إعدادات تثبيت التطبيق.
- sw.js: تحديث كاش التطبيق لإظهار الإصدار الجديد.

طريقة التحديث من الهاتف:
1) افتح مستودع Noor-app على GitHub.
2) Add file > Upload files.
3) اختر الملفات الثلاثة من هذا المجلد.
4) ارفعها إلى جذر المستودع، وليس داخل مجلد فرعي.
5) وافق على استبدال الملفات القديمة ثم Commit changes.
6) انتظر نشر GitHub Pages، ثم افتح رابط Pages مع إضافة ?v=2 إلى نهايته.

تنبيه المحتوى:
- فهرس القرآن والنص العثماني يتم تحميلهما من AlQuran Cloud عند الاتصال بالإنترنت.
- السورة التي تفتحها تُحفظ محليًا بعد تحميلها.
- مكتبة الأذكار في هذه النسخة توسعة أولى موثقة بمراجع ظاهرة، وليست كل أبواب حصن المسلم بعد. راجع النصوص والمصادر قبل اعتماد التطبيق كمرجع ديني نهائي.
- لا يوجد اشتراك أو إعلانات داخل التطبيق.
